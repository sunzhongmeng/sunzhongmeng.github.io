# ZU47DR 载板 10G SFP+ 电路设计

版本：V1.2｜日期：2026-11-06

本次更新：增加I²C用途说明、“使用I²C”和“不使用I²C”两种电路及互斥装配表；补充与QSFP28共存的管理总线接法。

## 1. 设计目标、结论及边界

对象为 ZU47DR 载板的单口 10GBASE-R，使用普通 10GBASE-SR/LR SFP+ 光模块。控制接口只有 SCL、SDA 接 PL 普通 IO；高速数据使用一组 GTY；其余控制输入由电阻固定，状态输出只驱动本地指示灯。

推荐默认方案：TX_DISABLE 通过 0 Ω 接地；RS0、RS1 各通过 4.7 kΩ 上拉；MOD_ABS、RX_LOS、TX_FAULT 各用独立的 SN74LVC1G14DBVR 单通道施密特反相器驱动指示灯。普通 NPN 和内置电阻数字三极管的替代方案见第 7、8 节。三种驱动电路是互斥装配选项，不能并接到同一状态网络。

这是一份可用于绘制原理图的电路设计说明，不是已完成 PCB 信号完整性验证的制造文件。核心板 GTY 引脚、现有隔直电容及 PL Bank VCCO 尚未提供，因此本文件以功能网络名定义连接，并给出 I²C 两种电压配置。所有电流、亮度计算中明确区分器件保证值、工程假设与待实测项目。

## 3. 指示灯颜色有没有标准依据

### 3.1 明确区分接口标准与颜色惯例

SFP+ 电气规范规定状态脚含义、电平和接口行为，没有要求主机必须配置这三盏灯，也没有将某个 SFP+ 状态脚绑定到特定 LED 颜色。不能宣称“TX_FAULT 红色、RX_LOS 黄色是 SFP+ 标准规定”。

IEC 60073 提供通用颜色语义。Eaton 的电气设计手册也按 DIN EN 60073 整理了指示灯颜色及含义。可据此制定本产品的面板规范，但不能据此直接宣称整机通过某种安全标准认证。

| 颜色 | 通用语义 | 本载板建议 |
|---|---|---|
| 红 | 故障、危险或需立即关注的状态，具体取决于应用 | TX_FAULT 发射故障 |
| 黄/琥珀 | 异常、警告或需关注的状态 | RX_LOS；需要提示缺席时也可用于 ABSENT |
| 绿 | 正常状态 | 可用于 PRESENT、接收信号存在或电源指示，但必须准确标注 |
| 白 | 中性信息 | 不把空插槽视为异常时，可将 ABSENT 改为白色 |

推荐初版采用：ABSENT 黄、RX LOS 黄、TX FAULT 红；若空插槽是产品正常工作状态，ABSENT 使用白色更合理。该选择是产品定义，不是接口兼容性条件。

### 3.2 灯的语义和真值

| 模块情况 | ABSENT 黄 | RX LOS 黄 | TX FAULT 红 |
|---|---|---|---|
| 未插模块，接口已供电 | 亮 | 亮 | 亮 |
| 已插模块、接收有光、无发射故障 | 灭 | 灭 | 灭 |
| 已插模块、接收无光、无发射故障 | 灭 | 亮 | 灭 |
| 已插模块、发射故障 | 灭 | 由接收状态决定 | 亮 |

表中“有光”表示超过模块 LOS 判决门限，并不证明接收数据有效；上电初始化时状态也可能短暂变化。未插模块时三个网络被主机上拉，因此三灯均亮，这是简单电路的确定行为。操作时先看 ABSENT，再解读其他两灯。

如果要求未插模块时只亮 ABSENT，需增加硬件门控：LOS_LED = NOT(MOD_ABS) AND RX_LOS；FAULT_LED = NOT(MOD_ABS) AND TX_FAULT。不占 PL IO，但增加逻辑器件；本文件默认不屏蔽，保留直接状态含义。

RX_LOS 灭灯不能标成 LINK，更不能标成 ACT。真正的 LINK 应依据 PCS/链路状态，ACT 应依据收发活动，需要以太网逻辑提供输出。单靠这三个模块状态脚无法实现。

## 5. 控制电阻选型与计算

### 5.1 TX_DISABLE

R1 默认装 0 Ω，将 Pin 3 拉低，允许模块发送。模块内部存在约4.7～10 kΩ上拉，悬空或拉高关闭发送。

最大内部上拉电流估算：3.46 V / 4.7 kΩ ≈ 0.736 mA，0 Ω 接地没有问题。若改为1 kΩ下拉，与内部4.7 kΩ形成分压，高电源时约0.607 V，虽通常满足低电平，但裕量不如0 Ω，所以推荐0 Ω。

调试禁光：拆掉 R1，让模块内部上拉；R2 为可选明确上拉，不与 R1 同装。也可将 R1 替换为两针短路帽，拔帽禁光。

固定拉低的代价：FPGA 未配置时也允许光模块发射；无法通过这个硬件脚执行 TX_DISABLE 故障复位脉冲。可选软禁光能力由模块声明决定，不能当作硬件控制的等价保证。需要恢复故障时，可手工改变跳帽或断电重插模块。

### 5.2 RS0/RS1

默认各4.7 kΩ上拉至VCCT_SFP。传统10G SFP+速率选择中，RS0对应RX、RS1对应TX，高表示大于4.25 GBd。固定10G模块可能忽略它们，双速模块或其他应用编码必须核对其手册。

以模块内部30 kΩ下拉作保守名义估算：V_RS = 3.14×30/(30+4.7) ≈ 2.715 V，足够超过2.2 V的主机高电平输出目标。内部下拉大于30 kΩ时电压更高。

若旧模块将RS1接地，上拉电流最大约3.46/4.7k＝0.736 mA，电阻功耗约2.55 mW。用4.7 kΩ而不是直接接3.3 V，可避免硬短路；这不代表10G逻辑配置可自动兼容旧1G模块。

## 6. 指示灯驱动方案A：单通道施密特反相器，默认推荐

### 6.1 选型与接线

选 U1/U2/U3＝SN74LVC1G14DBVR，SOT-23-5，每个状态独立一颗。选反相器是为了用下灌电流驱动LED，实现“状态高→灯亮”。不要将普通同相缓冲器按相同接法替换，否则点亮逻辑反转。

| 器件/引脚 | 连接 |
|---|---|
| RP1 | 3V3_SFP → 10 kΩ → SFP_ABS |
| RP2 | 3V3_SFP → 10 kΩ → SFP_LOS |
| RP3 | 3V3_SFP → 10 kΩ → SFP_FAULT |
| U1 Pin2 A | SFP_ABS |
| U2 Pin2 A | SFP_LOS |
| U3 Pin2 A | SFP_FAULT |
| 各U Pin5 VCC | 3V3_SFP |
| 各U Pin3 GND | GND |
| 各U Pin1 NC | 不连接 |
| 各U Pin4 Y | 对应LED阴极 |
| D1阳极 | 经RL1＝1 kΩ接3V3_SFP；黄/琥珀，ABSENT |
| D2阳极 | 经RL2＝1 kΩ接3V3_SFP；黄/琥珀，RX LOS |
| D3阳极 | 经RL3＝1 kΩ接3V3_SFP；红，TX FAULT |
| C1/C2/C3 | 各100 nF，分别就近接各U Pin5与Pin3 |

状态高时U输出低，电流路径为3V3_SFP→限流电阻→LED→U输出→GND；状态低时输出高，LED两端压差很小而熄灭。

用施密特输入是为了容忍开漏上拉的慢边沿，避免普通逻辑门对输入转换速率的限制。SN74LVC1G04虽也能反相，但没有施密特迟滞，不作为本设计首选。单通道方案可以分散在面板灯附近；状态走线不要贴近GTY高速对。

### 6.2 状态上拉电流和电平裕量

以下用历史SFP+接口的0.7 mA低电平负载能力进行校核。10 kΩ、1%时：I_sink,max ≤ 3.46/9.9k ≈ 0.350 mA，远小于直接驱动LED通常需要的电流。加上约5 µA逻辑输入泄漏后仍有余量。

以电源3.14 V、上拉10.1 kΩ、模块高态吸入37.5 µA、逻辑输入吸入5 µA估算：V_H,min ≈ 3.14−(37.5+5)µA×10.1k＝2.711 V。低态按模块保证的0.4 V校核。该高低电平可覆盖3.3 V供电LVC施密特输入的判决范围；量产器件更改时仍应按实际VCC范围逐项核对门限表，不能用0.7×VCC替代施密特门限。

### 6.3 LED限流

计算式：I_LED＝(V_SUPPLY−V_F−V_OL)/R_LED。

以低正向压降的红色/黄绿色/琥珀LED为对象，工程估算V_F＝1.7～2.3 V，典型2.0 V，输出低压典型估算0.1 V：

- 典型：I＝(3.3−2.0−0.1)/1k＝1.2 mA。
- 较大电流：按3.46 V、V_F,min＝1.7 V、V_OL＝0及R_min＝990 Ω，I≤1.78 mA。
- 较小电流估算：按3.14 V、V_F＝2.3 V、V_OL＝0.4 V、R_max＝1010 Ω，I≈0.436 mA。
- 电阻最大功耗按1.76²/990≈3.13 mW，0402常见额定功率足够；默认1%、≥1/16 W即可。

V_F范围是选型输入，不是所有LED的共同保证。选0603高效率LED，厂家应提供低电流亮度/色坐标信息，最终以面板环境实测确认0.4～1.8 mA亮度。不要把标称20 mA时的V_F或亮度直接用于1 mA计算。绿色LED优先低V_F的GaP类黄绿色；若用蓝绿InGaN器件，3.3 V余量可能明显不足，必须重算。

该方案不消耗状态脚的基极电流，也没有三极管增益分散引起的亮度不确定性，因此推荐冻结为默认BOM。

## 7. 指示灯驱动方案B：普通NPN三极管

### 7.1 每路连接

对SFP_ABS、SFP_LOS、SFP_FAULT分别复制一套，X代表对应状态网络。

| 元件 | 连接/规格 |
|---|---|
| RP | 3V3_SFP → 4.7 kΩ、1% → X |
| RB | X → 47 kΩ、1% → Q基极 |
| RBE | Q基极 → 470 kΩ、1% → GND |
| Q | BC847B，Nexperia SOT23：Pin1 B、Pin2 E、Pin3 C |
| Q发射极 | GND |
| Q集电极 | 对应LED阴极 |
| LED阳极 | 经RLED＝2.2 kΩ接3V3_SFP |

状态高时基极获得电流，NPN导通，LED亮；状态低时NPN截止。RBE接在实际基极与发射极之间，不是把47 kΩ串联电阻前的状态网络直接下拉。

### 7.2 计算

为得到清晰的近似，假定V_BE＝0.8 V、电源3.3 V、模块高态无额外吸入电流：

I_RB＝(3.3−0.8)/(4.7k+47k)＝48.36 µA；

I_RBE＝0.8/470k＝1.70 µA；

I_B≈46.66 µA；X≈0.8＋48.36µA×47k＝3.073 V。

若再计入模块37.5 µA高态吸入电流，通用式为：

I_RB＝(V_SUPPLY−V_BE−I_MODULE×RP)/(RP+RB)。

在3.14 V、V_BE假设0.9 V、RP＝4.747 kΩ、RB＝47.47 kΩ时，I_RB约39.5 µA；扣除RBE电流后I_B约37.6 µA。此处0.9 V是计算假设，不是BC847B在该工作点的全温保证值。

RLED＝2.2 kΩ、V_F≈2 V、V_CE≈0.1 V时LED约0.545 mA；按3.46 V、V_F＝1.7 V及晶体管压降0计算，最大约0.81 mA。所需强迫β约0.81mA/37.6µA＝21.5，驱动量级合理。

状态低时，上拉电流上界3.46/4.653k≈0.744 mA是忽略VOL的过保守上界。按接口VOL＝0.4 V测试点算，上拉电流约(3.46−0.4)/4.653k＝0.658 mA，基极支路还会分流少量电流，不增加模块下灌负担。此方案不得将RP任意改小。

BC847B的hFE分档是在指定IC、VCE、温度条件下保证的；不能将其2 mA、5 V条件下的hFE最小值当作0.5 mA饱和工作及全温的保证。该方案按强迫β进行工程设计，并需实测低温点亮、高温熄灭和状态电平。对于需要明确逻辑门限保证的量产方案，优先方案A。

## 8. 指示灯驱动方案C：带内置下拉的数字三极管

### 8.1 器件选择与适用性

候选Q＝ROHM DTC144EKAT146，内置串联输入电阻R1＝47 kΩ，以及基极到发射极的R2＝47 kΩ。这正是“带内置下拉电阻”的数字NPN；R2不是一只独立接在外部输入IN与地之间的47 kΩ电阻。

不能只看“三极管能承受100 mA”就认为开漏状态脚能驱动几毫安LED。真正的限制是主机上拉供给的输入电流、内置电阻、公差、导通曲线和熄灭泄漏。

### 8.2 每路连接

| 元件 | 连接 |
|---|---|
| RP | 3V3_SFP → 4.7 kΩ、1% → 状态X |
| Q输入IN | 状态X，不再添加外部基极电阻 |
| Q发射极/公共端GND | GND |
| Q输出OUT/集电极 | LED阴极 |
| LED阳极 | 经RLED＝4.7 kΩ接3V3_SFP |
| RB、RBE | 不装，使用内置R1/R2 |

此处按IN/OUT/GND功能端定义；DTC144E系列有多种封装及不同排列，必须按照EKA具体封装图将功能映射到焊盘，不直接套用BC847B或其他数字三极管符号的数字脚号。

### 8.3 名义计算和公差分析

以3.3 V、V_BE＝0.8 V、RP＝4.7 kΩ、R1＝R2＝47 kΩ估算：

I_IN≈(3.3−0.8)/(4.7k+47k)＝48.36 µA；

I_R2≈0.8/47k＝17.02 µA；I_B≈31.34 µA；X约3.073 V。

考虑模块高态吸入37.5 µA时，I_IN约44.95 µA，I_B约27.93 µA。LED典型约(3.3−2−0.1)/4.7k＝0.255 mA；最大估算(3.46−1.7)/4.653k＝0.378 mA。内置R2消耗一部分输入电流，所以这里用较大的LED限流电阻。

ROHM给出的R1范围为32.9～61.1 kΩ，R2/R1比例为0.8～1.2。两只电阻有比例约束，不应把R1最大与一个不满足比例的R2最小随意组合。

举例：取R1＝61.1 kΩ、R2＝0.8R1＝48.88 kΩ、电源3.14 V、RP＝4.747 kΩ、模块吸入37.5 µA、V_BE假设0.9 V：

I_IN≈(3.14−0.9−37.5µA×4.747k)/(61.1k+4.747k)＝31.3 µA；

I_B≈31.3−0.9/48.88k＝12.9 µA；最大LED电流0.378 mA时所需强迫β约29.3。

高态节点仍约2.81 V，不会像低输入电阻数字管那样显著拉低状态网络。不过这只是工作点估算，不能据此生成全温饱和压降保证。

### 8.4 为什么数字三极管不作为默认方案

数据手册给出的VI(on)、GI及VO(on)均有特定输出电流、输入电流和温度条件；不完全覆盖本方案由弱上拉供电的约0.25 mA LED工作点。其VI(off)测试也不能直接解释为低电平时LED电流严格为零。高效率LED在极小电流下可能微亮。

因此该电路适合作为降成本/少元件的样机候选：必须验证模块输出0.4 V时LED确实灭、温度范围内高态亮度足够、实际模块状态脚高低电平合格。若要求无需依赖样机分档即可获得清晰的门限保证，选择方案A。不要将DTC114等较低输入电阻器件不经重算直接替换DTC144E。

如需数字三极管且又要求更大LED电流，可靠做法是先用逻辑门隔离状态脚，再驱动数字管；但对于1～2 mA指示灯，逻辑门本身已经能驱动，增加数字管通常没有必要。

## 10. I²C用途及使用/不使用两种电路

### 10.0 I²C的作用和方案选择

I²C属于管理通道，不传输10G以太网帧。数据走一组GTY TX/RX；SCL/SDA用于访问模块内部信息与寄存器。SFP+管理映射主要按SFF-8472，物理与时序按SFF-8419，具体功能需模块声明支持。

| 管理功能 | 典型内容 | 不使用I²C后的影响 |
|---|---|---|
| 模块识别 | 厂家、型号、序列号、支持速率 | 软件无法自动识别/检查替换模块 |
| DDM诊断 | 温度、电压、激光偏置、收发光功率 | 无法读取这些测量值 |
| 软件控制 | 模块支持时的软禁光、速率等 | 仅依赖控制脚及上电默认配置 |
| 诊断状态 | 模块声明的状态和告警 | 仍可看独立LOS/TX_FAULT硬件灯，但缺少详细信息 |

固定10G SR/LR模块通常可以凭默认配置运行，但这不是对所有模块的保证。省去I²C之前应固定模块型号，确认无需管理写入即可启动、重插和恢复。GTY/PCS/以太网逻辑本身仍需正常初始化，不使用I²C并不等于FPGA不需要配置。

| 方案 | 管理连接 | 普通PL IO | 推荐用途 |
|---|---|---:|---|
| A：使用I²C | 接PL，单模块按10.1/10.2；双模块按10.4 | 共用总线时合计2 | 默认推荐，保留识别、诊断与配置 |
| B：不使用I²C | SCL/SDA仅上拉，和PL物理断开，见10.5 | 0 | 固定已验证模块、接受无诊断的产品 |

以下10.1/10.2是方案A单模块的两种电平实现，不能并装。SFP和QSFP都需要管理时以10.4为准，不再把两份独立电路直接并到PL。

### 10.1 PL Bank为3.3 V且供电时序兼容

| 网络 | 连接 |
|---|---|
| SFP_SDA | J1 Pin4 → 33 Ω → PL_SDA |
| SFP_SCL | J1 Pin5 → 33 Ω → PL_SCL |
| SDA上拉 | SFP_SDA → 4.7 kΩ → 3V3_SFP |
| SCL上拉 | SFP_SCL → 4.7 kΩ → 3V3_SFP |

PL采用IOBUF开漏驱动：只拉低或者高阻释放，不能主动输出高。初版100 kHz；PL_SCL应可回读以支持时钟拉伸。两个信号各设不带长支线的低速测试点。

直接连接仅适用于实际IO支持3.3 V且电源时序合格的Bank。不能因为板上有3.3 V电源，就认为任意PL IO可承受3.3 V。模块有电、Bank无电时的反灌必须单独检查。

### 10.2 PL Bank为1.8 V或2.5 V

用U4＝PCA9306DCUR：

| Pin | 名称 | 连接 |
|---:|---|---|
| 1 | GND | GND |
| 2 | VREF1 | VCCO_I2C，100 nF到GND |
| 3 | SCL1 | PL_SCL；4.7 kΩ上拉到VCCO_I2C |
| 4 | SDA1 | PL_SDA；4.7 kΩ上拉到VCCO_I2C |
| 5 | SDA2 | SFP_SDA；4.7 kΩ上拉到3V3_SFP |
| 6 | SCL2 | SFP_SCL；4.7 kΩ上拉到3V3_SFP |
| 7 | VREF2 | 与Pin8相连，形成BIAS节点 |
| 8 | EN | BIAS经200 kΩ连接3V3_SFP |

VREF2不是普通直接接3.3 V的电源脚；按TI参考电路使用200 kΩ偏置。无额外PL使能IO。该自动偏置接法不应未经时序分析就当作任意顺序上下电的万能隔离器；需验证VREF1掉电后的节点状态、Bank钳位及泄漏。若系统要求可证明的任意时序隔离，另选带明确定义掉电隔离功能的I²C转换器并核对数据手册。

### 10.3 I²C上拉计算

RC近似10%～90%上升时间t_r≈0.8473RC。4.7 kΩ、总电容100 pF时约398 ns，适合100 kHz的起始设计，但不能仅凭该阻值宣称支持400 kHz；400 kHz常用300 ns上升时间目标下，R_max≈300ns/(0.8473×100pF)＝3.54 kΩ，还应满足SFP+规范的更具体要求。当前SFF-8419表8-1在100 pF、400 kHz条件给出的最大上拉为3 kΩ，故如升级400 kHz，可先选2.7 kΩ并重新校核两侧电流、电容及波形。

PCA9306通道拉低时，两边上拉电流会共同流向当前下拉端，不能只算模块侧。以1.8 V/3.3 V、两侧4.7 kΩ、VOL＝0.4 V估算，总电流约(1.8−0.4)/4.7k＋(3.3−0.4)/4.7k＝0.915 mA；另计转换器压降和容差。若两侧电压或上拉改变，应重新计算。

### 10.4 方案A：同时管理SFP+与QSFP28

两只模块都有0x50管理地址，不能直接并联。采用一颗TCA9543APWR：A1/A0接地，地址0x70；上游接PL；CH0接本SFP+，CH1接QSFP28。其完整14脚电路和状态读取见配套《ZU47DR_QSFP28_100G_Circuit_Design.md》第3节。

本SFP+侧接线为：

| 本SFP+网络 | 连接到TCA9543A | 本地上拉 |
|---|---|---|
| J1 Pin4 SDA | Pin5 SD0，经可选33 Ω串阻 | 4.7 kΩ至3V3_SFP |
| J1 Pin5 SCL | Pin6 SC0，经可选33 Ω串阻 | 4.7 kΩ至3V3_SFP |
| PL_SDA | Pin13 SDA | 4.7 kΩ至VCCO_I2C |
| PL_SCL | Pin12 SCL | 4.7 kΩ至VCCO_I2C |

TCA9543A按最低总线电压/Vpass要求选择供电；按配套文档以VCCO_I2C供电并核对门限及供电时序，默认不再加PCA9306。U4及其200 kΩ偏置不装，也不额外保留一条绕过MUX直达PL的并联支路。

写0x70控制字0x01并STOP后访问SFP的0x50/0x51；写0x02并STOP后访问QSFP。绝不写0x03同时开通两路。选通道和模块事务使用互斥锁；上拉电阻按开通后总下灌电流计算，每段仅一组。

### 10.5 方案B：完全不使用I²C的实际接线

SCL/SDA不用时也建议在模块侧保持空闲高，采用本地4.7 kΩ上拉；不接地、不连接到掉电或悬空的PL IO。下表可直接绘制为方案B原理图：

| 引脚/器件 | 方案B连接 |
|---|---|
| J1 Pin4 SDA | 本地SFP_SDA → 4.7 kΩ → 3V3_SFP；保留TP_SDA |
| J1 Pin5 SCL | 本地SFP_SCL → 4.7 kΩ → 3V3_SFP；保留TP_SCL |
| SDA至主机链路 | 串联连接电阻DNP，开路；不接PL、不接MUX |
| SCL至主机链路 | 串联连接电阻DNP，开路；不接PL、不接MUX |
| PCA9306 U4、200 kΩ及低压侧上拉 | 不装 |
| TCA9543A | 两个模块都不用管理时整颗不装；其他端口要管理时按10.6处理 |
| Pin3 TX_DISABLE | R1=0 Ω接地，允许发送 |
| Pin7 RS0、Pin9 RS1 | 各4.7 kΩ上拉VCCT_SFP，按固定模块要求选择 |
| Pin2 TX_FAULT、Pin6 MOD_ABS、Pin8 RX_LOS | 继续按原文上拉并驱动本地指示灯 |
| 数据、时钟与电源 | 仍按第4、11、12节连接，没有因管理接口取消而省去 |

模块侧两根线只有上拉和测试点，没有主机产生时钟。按模块引脚输入电流10 µA量级估算，3.14 V、4.747 kΩ时高态约3.093 V；每线误接低时上拉电流不超过约3.46/4.653k=0.744 mA。该上拉值是本设计空闲偏置选择，不是标准强制的“免I²C电路”。若具体模块手册规定不用时NC或其他方式，按其要求核对。

测试点可接外部开漏I²C工具做调试，但这时属于临时使用I²C；工具电平应为3.3 V，避免重复上拉和反灌，不接5 V推挽接口。

### 10.7 不用I²C的选型与验收要求

1. 固定厂家、完整型号与必要的固件版本，确认默认10G、默认发射允许、RS含义和无需软配置。
2. 分别进行冷启动、FPGA晚配置、热插拔、复位/断电恢复测试，并做双向10G流量和误码测试。
3. 失去DDM不影响GTY传数据，但减少故障定位能力；LOS/TX_FAULT灯仍按模块硬件脚工作。
4. 固定TX_DISABLE低时，FPGA未就绪也可能发射；如需禁光可保留跳帽，不把“无I²C”当作默认禁光。
5. 更换模块型号必须重新验证，不能对外宣称免管理方案兼容所有SFP+。不用I²C不等于一套经过完整管理一致性验证的通用SFP+主机。

## 11. 3.3 V供电、滤波与计算

### 11.1 默认接线

本设计假定载板已提供受保护的3.3 V电源，不在此文件中重新设计12 V→3.3 V稳压器。

| 位号 | 连接及参数 |
|---|---|
| C10 | 3V3_SFP→22 µF→GND |
| C11 | 3V3_SFP→100 nF→GND |
| FB1 | 3V3_SFP→磁珠→VCCR_SFP |
| C12/C13/C14 | VCCR_SFP分别经10 µF/1 µF/100 nF到GND，靠近Pin15 |
| FB2 | 3V3_SFP→磁珠→VCCT_SFP |
| C15/C16/C17 | VCCT_SFP分别经10 µF/1 µF/100 nF到GND，靠近Pin16 |

磁珠的设计筛选条件：约120 Ω@100 MHz、额定电流≥1 A、DCR≤50 mΩ，并检查实际直流偏置下的阻抗曲线。这里不以未核实的具体磁珠料号替代这些要求。0603/0805按电流和阻抗曲线选择。电容用X7R、≥10 V，按3.3 V偏置下有效容量选择；10 µF优先考虑0805/1206并核对厂家曲线。

该滤波网络是工程起始方案，不是SFF规范唯一指定电路；标准中的电源测试参考滤波器也不等同于主机必须照抄的拓扑。

### 11.2 电流和压降预算

以预期模块最大功耗2 W举例：I_module≈2W/3.14V＝0.637 A；加入三盏约1～2 mA指示灯及设计余量，单口可先按1 A连续供电能力规划。1 A是本设计预留值，不是所有SFP+模块的标准最大电流。高功耗铜缆电口模块需重新做电流和散热预算。

若某支路0.5 A、磁珠DCR＝50 mΩ，则压降25 mV，功耗12.5 mW。接口最低电压应满足：V_connector,min＝V_source,min−I×R_path−瞬态跌落≥3.14 V。

若源电压3.3 V±2%，最低3.234 V，只剩94 mV覆盖走线、磁珠、开关及瞬态；不能忽略串联器件压降。3.3 V±5%的最低值为3.135 V，已经小于3.14 V，因此不能在未补充精度预算时直接宣称满足接口要求。

热插拔浪涌近似I＝C×dV/dt。例如总有效电容40 µF、上升时间1 ms时仅电容充电就约132 mA，另加模块工作电流。模块内部电容、接触反弹及LC振铃也必须纳入实测。

若上游稳压器无法承受，应增加带限流和软启动的电源开关/电子保险丝，固定硬件使能，不占PL IO。不要把TPS22918等仅控制上升时间而没有限流的普通负载开关称为短路保护器；也不要认为输入开机软启动能自动限制已上电插座再次插模块时的全部浪涌。默认方案依赖上游保护，并需验证插拔不扰动其他电路。

## 12. 高速接口与参考时钟

GTY TXP/N分别接J1 Pin18/19；J1 Pin13/12分别接GTY RXP/N，按模块接收和发送方向理解，不能将TX接到RD。

普通符合SFI的SR/LR模块内部包含AC耦合，默认载板直连，不额外串联隔直电容。若核心板已串电容，需将其计入完整通路；如兼容DAC或非标准模块，则根据模块和GTY要求重新确定耦合位置。不要在已完成的高速路径上机械增加0 Ω或DNP焊盘。

GTY按10.3125 Gb/s配置，使用10GBASE-R对应PCS/PMA。SFP+模块本身不接156.25 MHz参考时钟；该差分时钟送所选GTY Quad可用的MGTREFCLK。156.25 MHz是常用实现，最终参考时钟与PLL组合由IP和器件支持范围决定。

GTY片内终端按IP/UG578设置，载板不再跨接100 Ω。HMC7044在VCO＝2400 MHz时不能通过整数分频准确得到156.25 MHz；如载板没有现成时钟源，可使用满足GTY抖动及电平要求的独立156.25 MHz差分时钟源。源类型、AC耦合与共模必须与MGTREFCLK输入要求一起选定，不能仅按“LVDS”名称连线。

## 13. PCB、笼子及测试点

- 高速对按100 Ω差分设计，具体线宽/间距依实际叠层场求解；不直接套用其他板的线宽。
- 以每对内部时延差≤1 ps作为初始布线控制目标，再按通道仿真确认；这不是声称标准统一要求某个毫米数。两组TX/RX之间无需机械等长。
- 优先少过孔、短通道、连续参考面；检查核心板连接器和载板连接器造成的损耗、反射及串扰。长残桩需考虑背钻。
- 高速线上不引出长支线测试点，不直接加普通大电容TVS。需要ESD器件时必须核对其10G通道损耗和S参数。
- 笼子按厂家推荐焊脚/压接孔接机壳屏蔽回流，面板开口提供短低阻连接。无独立机壳地时，预留与PCB地的低阻连接方案，经EMC验证确定；不要仅用一根细长线接笼子。
- 低速测试点：TP_DIS、TP_RS0、TP_RS1、TP_ABS、TP_LOS、TP_FAULT、TP_SCL、TP_SDA及两个模块电源。

## 15. 软件及上电验证

本节I²C读写步骤适用于方案A；方案B跳过模块管理读写，执行第10.7节的固定模块验证。方案B没有I²C应答，就不能使用原有应答轮询来判断模块在位，仍以本地MOD_ABS灯和链路测试判断。

1. 首次上电不插模块，测3V3_SFP及滤波支路；默认三盏状态灯应亮。检查低速信号最高电压不超过其供电及模块允许范围。
2. 插入模块后ABS应低，ABSENT灯灭。用示波器检查3.3 V跌落、振铃及相邻电源是否受扰动。
3. 无接收光时确认LOS高且黄灯亮；接入匹配波长、功率合格的光信号后LOS应低。灯灭不等于10G链路已通。
4. 初始100 kHz读取0x50模块信息；模块支持时读取0x51诊断。这里是7位地址，不要与传统A0h/A2h的8位地址表示混淆。
5. 无MOD_ABS输入时，可轮询I²C应答判断模块是否可访问，但无应答也可能是上电延迟、掉电或总线故障。
6. 没有额外TX_DISABLE IO时，在Ethernet IP中将相应控制信号配置为允许运行；没有LOS硬件输入时，应使用PCS同步/块锁定等内部状态处理收发有效性，不能把一盏灯的状态当成FPGA自动知道的输入。
7. 需要测试TX_FAULT灯时，不在模块输出已拉低的情况下外部强拉高。可先断开模块信号侧，通过主机上拉/接地模拟状态，或者按厂家故障测试流程验证。
8. 方案B/C额外验证：低态0.4 V模拟下是否微亮；高态最小供电及最高/最低工作温度下是否足够亮；测状态网络电压和LED电流，不能仅凭肉眼亮灭通过电气验收。
9. 最终执行GTY PRBS/误码测试和10G以太网双向流量测试，必要时测SFI眼图、回损和通道S参数。完成这些测试后再冻结高速参数和PCB版本。
