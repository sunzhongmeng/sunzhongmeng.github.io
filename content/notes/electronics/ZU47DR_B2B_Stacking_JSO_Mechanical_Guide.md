# ZU47DR 核心板与载板 B2B 堆叠及 JSO 机械设计指南

版本：V1.0  
日期：2026-11-06  
适用连接器：载板 LPAF-50-03.0-L-08-2-K-TR；核心板 LPAM-50-01.0-L-08-2-K-TR。

> 本文可用于结构与 PCB 协同设计评审。厂家数据以文末原始图纸为准；文中明确标注的“工程建议”属于本项目设计建议。当前未获得核心板机械 CAD、实际板厚、安装孔坐标及散热器模型，因此不提供未经核对的量产孔位坐标，也不认定现有核心板能够直接安装 JSO。

## 1. 设计结论

1. 两个指定料号的连接器标称配合高度为 **4.00 mm**，指两块 PCB 相向安装表面之间的距离。[1][2]
2. 对多组高针数 B2B 配合、需要拆装调试的 47DR 核心板，优先评估 **JSO 助拔螺柱**；普通 SO 支撑柱适合少拆装或配有专用平行插拔工装的方案。
3. 4 mm 堆叠的目录对应配置为 **JSO-0415-01**。其 A 尺寸为 4.15 mm，不应自行用普通 4.15 mm 铜柱替代。[3]
4. JSO-0415-01 采用压入式结构，涉及专用防转孔型、板厚及安装工艺；不能把现有 M2/M2.5/M3 通孔直接视为兼容孔。
5. 散热器应有明确的支撑和夹紧路径。JSO 的板间支撑功能不能替代 RFSoC 散热器的压力控制与背板设计。
6. 若核心板现有孔不兼容，应采用原有孔位对应的精密支撑件及外部插拔工装，或重新设计经过验证的转接框架；不要在已焊接的核心板上直接扩孔试装。

## 2. 连接器配合高度与总高度

| 项目 | 数值或说明 |
|---|---|
| 载板插座 | LPAF-50-03.0-L-08-2-K-TR |
| 核心板插头 | LPAM-50-01.0-L-08-2-K-TR |
| 单组触点数 | 50 × 8 = 400 |
| 标称板间距 | 4.00 mm |
| 无外侧元件的板卡总厚度 | 载板厚度 + 板间距 + 核心板厚度 |

AMD ZCU216 用户指南列出了完全相同的连接器组合，并注明 4.00 mm 配合高度。[1]

例如两块 PCB 均厚 1.6 mm，按连接器标称板间距计算，总厚度为 7.2 mm。实际结构图应使用选定支撑系统的装配高度及公差，再叠加芯片、散热器、螺钉和机箱间隙，不能把 7.2 mm 当作整套组件高度。

### 2.1 为什么 JSO 是 4.15 mm？

Samtec 目录将 JSO 的 `-0415` 配置用于 4 mm 连接器堆叠。[3] 其机械图注说明支撑高度比连接器标称堆叠高度增加 0.15 mm，以考虑工艺变量。[4]

应将其理解为厂家的配套支撑设计，而不是任意拉开连接器的许可。最终要核对连接器焊后位置、JSO 安装状态及板卡平行度。结构 CAD 中不能同时把同一板间距刚性约束为 4.00 mm 和 4.15 mm。

## 3. SO 与 JSO 方案比较

| 比较项 | SO 普通支撑柱 | JSO 助拔螺柱 |
|---|---|---|
| 支撑固定 | 刚性支撑板间结构 | 具备支撑功能，同时提供辅助分离机构 |
| 拆卸 | 松开螺钉后仍需外力拔开连接器 | 利用嵌套螺旋机构逐步分离板卡 |
| 多连接器应用 | 通常需要插拔工装控制平行度 | 更适合需要可控拆装的应用 |
| 空间与成本 | 通常更简单、成本更低 | 机构较复杂，需要额外操作空间 |
| 孔位兼容性 | 可按已有孔位设计配套件 | 必须匹配具体 JSO 孔型及板厚 |
| 装配风险 | 手工拉拔时容易单侧先分离 | 操作不均匀同样可能使 PCB 倾斜 |

厂家说明 JSO 的嵌套结构有助于配合与分离，尤其适用于多连接器应用。[2] 产品页也明确列出 LPAM/LPAF 为适用系列。[5]

**本项目工程建议：**研发版优先评估 JSO；量产版若不需要频繁拆卸，可根据成本、工装和维护要求保留 JSO 或采用 SO。抗振性能取决于完整固定结构、预紧及验证结果，不能仅根据支撑柱名称判断。

## 5. 安装孔详细设计要求

### 5.1 孔型：带防转平面的圆形开孔

JSO Figure 1 的推荐开孔不是普通圆形螺钉通孔。外圆为 Ø6.35 mm，底部有一个平面，圆弧顶部至该平面的总高度为 6.00 mm REF。[4]

用于理解轮廓时，若圆心取 (0,0)，半径为 3.175 mm，平面位于圆心下方约 2.825 mm。此处坐标只是根据标注计算的几何解释，**不作为制造公差或独立加工依据**。实际使用厂家 CAD/经确认的孔型，不能仅在 PCB 软件中画 Ø6.35 mm 圆孔替代。

图纸将该孔型用于 `-01: Press-In and Jack Screw`。上下两板涉及的安装位置都应按实际总成配合关系建模，核对各子件的安装面和朝向，不能只修改载板而假设核心板自动兼容。

### 5.2 PCB 工程实现流程

1. 在机械层建立独立的 JSO 孔型，保留圆弧、平面、圆心及方向标识。
2. 将孔轮廓输出到板框/机械铣削层，并在制板说明中注明加工方式；不要只画在丝印上。
3. 对孔壁是否金属化、压入接触区表面状态及成品尺寸，取得厂家和板厂一致确认。工程起点可按机械非金属化孔评估，但不能把这一点标成 Samtec 已明确要求。
4. 与板厂确认内铣刀具和端部圆角能否满足实际金属件。孔型平面两端的加工圆角可能影响防转和压入。
5. 对孔周全部铜层设置机械安全间距，禁止非预期电源铜、信号线及过孔进入金属件可能接触区。
6. 设置两面元件禁布，至少覆盖厂家 Ø8 mm 包络，再加入实际公差和操作余量。
7. 输出带尺寸的机械孔表；Gerber/ODB++、钻铣文件和装配图中的孔位必须一致。
8. 首批制作同板厚、同孔工艺的试片，验证压入力、板材损伤和防转效果，再用于正式核心板总装。

### 5.3 成品板厚与公差

工程示例：若板厂给出 1.60 ±0.16 mm，最小可能厚度为 1.44 mm，不能仅凭标称厚度判定满足 1.57 mm 要求。应收紧成品板厚范围，或让厂家评估实际板厚适配性。

不要通过临时加垫片自行补偿不合格板厚。垫片可能改变咬合位置、支撑基准和机构行程。

### 5.4 孔位和连接器必须共用基准

建立核心板机械坐标系：以板边/机械基准定位，以同一坐标系给出所有 B2B 连接器和安装孔位置。载板按装配坐标变换建立配对位置，检查核心板底视图与载板顶视图的镜像关系。

| 必须标注 | 要求 |
|---|---|
| X、Y 坐标 | 来自核心板权威机械图或 CAD |
| 平面方向 | 每个防转孔分别标注，不能只给中心点 |
| 孔位公差 | 根据多连接器装配公差链确定，本文不虚设统一值 |
| 孔型公差 | 采用厂家确认的成品孔要求 |
| 与板边距离 | 根据剩余板材强度、压入载荷及工具空间确定 |
| 基准关系 | 安装孔、连接器、散热器及机箱共同评审 |

不要靠拧紧 JSO 把横向错位的连接器强行拉到位。多个刚性固定点会形成装配约束，必须在样机上验证无需强迫即可就位。

## 6. 安装孔位置与支撑布局

以下为工程建议，并非厂家指定的统一孔位模板。

### 6.1 布局原则

- 优先沿用核心板已批准的机械安装区域，避开 BGA、DDR、电源及 RF/GTY 布线区。
- 支撑点尽量围绕连接器群分布，使插拔合力落在支撑点围成的范围内。
- 对称布置可减少单侧先分离的倾向；靠近连接器群可缩短 PCB 受力力臂，但必须留出焊接返修空间。
- 四角方案可作为初步评估起点，最终数量取决于板形、连接器分布、PCB 刚度及散热器重量，不能固定为“必须四个”。
- 不能为增加支撑点而占用核心板禁止开孔区域。

简化受力关系为 M = F × L：同样插拔力 F 下，施力点与连接器群之间的力臂 L 越大，PCB 弯曲风险越高。实际插拔力应使用对应规格的测试数据或实测值；不能用触点法向力乘针数代替插拔力。

### 6.2 现有核心板的三种处理方式

| 核心板状况 | 建议 |
|---|---|
| 已有匹配 JSO 孔型且满足板厚 | 按总成图核对朝向、空间并试装 |
| 只有普通螺钉孔 | 保留原孔，用配套 SO 和外部插拔工装；或验证专用转接框架 |
| 核心板仍可改版 | 与载板同步规划 JSO 孔型和散热固定孔 |

转接框架必须重新计算高度与受力，并验证不干涉板边连接器，不能将其视作无条件兼容的替代件。

## 7. 空间、禁布区及拆卸行程

### 7.1 区分三种空间

| 空间类型 | 应覆盖的内容 | 设计方法 |
|---|---|---|
| 静态包络 | 螺柱、垫圈、螺钉及板外突出部分 | 导入实际型号 3D，检查上下两面 |
| 工具包络 | 刀杆、批头、套筒及手工操作空间 | 按选定工具建立实体或圆柱包络 |
| 运动包络 | 助拔过程中核心板、螺钉及散热器的移动 | 检查从配合到完全分离的全过程 |

厂家 Ø8 mm 禁布区只是机械孔周的基本要求，不能认为“留 Ø8 mm 就一定能装卸”。散热器上方如果遮挡工具轴线，即使 PCB 上已禁布也无法操作。

工程计算建议：

`工具通道直径 ≥ 实际工具最大外径 + 2 × 径向操作余量`

`拆卸净空 ≥ 完全脱开连接器所需抬升量 + 取出余量`

抬升量应结合厂家机构行程和实际连接器确定，不能假定为 4 mm；4 mm 是配合板间距。

### 7.2 板间元件限高

对相向且投影重叠的两个元件，使用最坏情况检查：

`载板元件最大高度 + 核心板元件最大高度 + 安全间隙 ≤ 最小实际板间距`

元件高度应包含焊后离板高度；板间距应考虑支撑公差、板翘曲及装配变形。不要把 JSO 多出的 0.15 mm 全部当成新增元件空间。

### 7.3 其他空间约束

- 孔周金属接触面避免放置小型阻容、测试点和过孔。
- PCB 背面要检查压入底座、垫圈、工具和机箱底板之间的间隙。
- 保留散热器、风扇、线缆及 RF 接头的拆卸顺序空间。
- 核心板抬升时检查同轴线、电源线、风扇线是否受拉；必要时先拆线。
- 不要在 JSO 运动区域放置会被剪切或挤压的导热垫。

## 8. 散热结构与承力路径

### 8.1 推荐结构

对 47DR 核心板，优先评估芯片外侧散热器或冷板，采用经核算的弹簧螺钉、限位件及局部背板控制压力；JSO 负责板间支撑与辅助拆装。

散热器重量和运输惯性可由核心板周边支撑、结构框架或机箱承接，具体路径由结构设计确定。不要让散热器夹紧力通过 RFSoC 封装、PCB 弯曲和 B2B 连接器串联闭合。

### 8.2 散热孔与 JSO 孔的关系

| 项目 | 设计建议 |
|---|---|
| 孔位共用 | 默认分别设计；确需共用时，完整核算夹紧路径和高度公差 |
| 散热器遮挡 | 预留工具通孔，或确保先拆散热器后可接近全部 JSO |
| 防转平面 | 不作为散热器高扭矩固定的通用承力结构 |
| 背板 | 避开核心板底面元件及 JSO 子件；按接触风险设置绝缘与间隙 |
| 散热垫 | 按压缩率和公差确定厚度，不靠拧 JSO 调整压缩 |
| 固定到机箱 | 避免机箱、载板及核心板间形成相互冲突的刚性高度约束 |

### 8.3 热设计需要计算的内容

1. 功耗：采用核心板实际工作配置及测量值，不把整张载板输入功率直接当成 RFSoC 芯片功耗。
2. 温升：初步按 `允许总热阻 ≤ (目标最高结温 − 最高环境温度) / 芯片耗散功率` 分配热阻，再根据封装、导热界面和散热器建模验证。
3. 压紧力：导热界面所需载荷可按 `F = 压力 × 接触面积` 估算，再与封装和核心板允许载荷核对；本文不指定未经验证的统一压力。
4. 风道：4 mm 狭窄板间通道可能被连接器和元件遮挡，不应默认能够有效冷却核心板底面的电源及存储器。
5. 热胀冷缩：大型金属冷板与 PCB 的膨胀差可能引起剪切或翘曲，结构固定应进行温度范围验证。

## 9. 安装与拆卸流程

### 9.1 安装前

1. 核对 JSO 总成型号、零件完整性、PCB 成品板厚、孔型与方向。
2. 先在工艺试片上验证压入；使用支撑治具承接孔周载荷，避免压装力经过 BGA 或连接器焊点。
3. 依照厂家装配说明安装上下子件。不要用拧紧螺钉的方式代替未经确认的压入工艺，也不要敲击安装。
4. 检查散热器和线缆是否影响板卡平行配合。

### 9.2 配合与固定

1. 两块板在断电、ESD 防护状态下对准，确认所有 B2B 同时进入正确导向位置。
2. 保持平行施力，不以 JSO 强行纠正横向错位。
3. 在各点交替、小步操作；先确认实际结构是否允许通过螺钉辅助压合，不能只凭“助拔”功能假定具有无限压合能力。
4. 检查各支撑点贴合、板卡无明显弯曲、全部连接器就位，再按受控工艺固定。
5. 安装散热器，检查导热界面接触及板卡变形，然后复查连接器。

JSO 图纸给出的 2.5～3.5 in·lbf（约 0.28～0.40 N·m）是静态紧固参考，并以前提为：推荐板间距已经实现，且不损伤 PCB、硬件或其他器件。[4] **它不是压入扭矩、强行压合扭矩，也不是散热器螺钉扭矩。**实际装配应采用厂家确认的工艺和扭矩工具。

### 9.3 拆卸

1. 断电，按预定顺序解除线缆和散热结构对抬升的限制。
2. 各 JSO 点交替、小步操作，使核心板均匀抬升。
3. 出现异常阻力、单边明显抬升或 PCB 弯曲时立即停下，检查是否仍有固定点或线缆未解除。
4. 全部连接器完全脱开后再取出核心板；禁止从一个角猛拉或用螺丝刀撬板。

## 11. 评审与首件验收清单

- [ ] 核心板机械 CAD、板厚及成品板厚下限已确认。

## 12. 下一步需要取得的机械资料

本文已经给出可用于设计评审的完整要求；要输出可直接投板的安装孔坐标和最终结构，还需要：核心板外形及安装孔 DXF/STEP、连接器坐标、板厚公差、两面元件高度、散热器或冷板 STEP、机箱空间与维修方向。

在取得这些资料前，结论为：**按 4 mm 标称配合高度规划，优先评估 JSO-0415-01；现有孔位不兼容时采用原孔位 SO 加平行插拔工装。**
